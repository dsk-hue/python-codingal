Write a Python program that generates a random password every time the user presses Enter.

📌 Rules:

The password should be 8 characters long

It must contain:

at least one uppercase letter (A–Z)

at least one lowercase letter (a–z)

at least one digit (0–9)

at least one special character (like @, #, $, %)

🔁 Program Behavior:

Keep generating passwords until the user types "stop"

If the user presses Enter, generate a new password

If the user types "stop", end the program
