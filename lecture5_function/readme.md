In this assignment, you will create a Python program that calculates the area of different shapes. The goal is to help you understand how to use user input, conditional statements (if-elif-else), and basic mathematical formulas in Python.

Your program should display a menu with the following options: Triangle, Rectangle, Square, and Circle. The user will be asked to enter their choice by selecting a number from 1 to 4. Based on the selected option, the program should ask for the required measurements and calculate the area accordingly.

If the user selects Triangle, the program should ask for the base and height, and then calculate the area using the formula: (base × height) ÷ 2. If the user selects Rectangle, the program should ask for the length and breadth, and calculate the area using the formula: length × breadth. If the user selects Square, the program should ask for the side and calculate the area using: side × side. If the user selects Circle, the program should ask for the radius and calculate the area using: 3.14 × radius × radius.

Make sure your program uses input() to take values from the user and displays the result clearly using print statements. You should also handle invalid inputs. If the user enters a number other than 1 to 4, your program should display a message like “Invalid choice, please try again.”

As an optional challenge, you can improve your program by allowing the user to perform multiple calculations using a loop, or by formatting the output neatly using f-strings.
